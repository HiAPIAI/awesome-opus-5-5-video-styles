## Why sort by style

Opus 5.5 doesn't output video: it writes code that draws every frame, then renders an MP4. So the same prompt can come out as kinetic type one run and 3D or pixel art the next. <b>To get a look, you have to name it.</b> Each style here comes with real prompts plus a ready-to-paste style recipe.

## Use it in three steps

1. Pick a style below and open it.
2. Copy an example prompt and change the subject, or paste the style recipe after your own prompt. Every code block has a copy button.
3. Run it with Opus 5.5 in Claude Code. One [HiAPI](https://www.hiapi.ai/en) key is enough:

```bash
export ANTHROPIC_BASE_URL=https://api.hiapi.ai
export ANTHROPIC_AUTH_TOKEN=<your-hiapi-key>
claude --model claude-opus-5-5
```
